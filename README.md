Data Cleaning and Processing
Dataset-Netflix Movies and TV Shows
I completed a Data cleaning and preprocessing task as part of my Data Analyst Internship. The objective was to clean the raw dataset containing missing values, duplicate records, and inconsistent formats. 
I used Python and Pandas to explore the dataset with head(),info(),and describe(). 
I identified and handled missing values, removed confirmed duplicates, standardized category values and corrected data types. I checked for outliers and validated the result. Finally, I saved the cleaned dataset as a csv file and summarized the changes. This task showed me why data cleaning is important before analysis and visualization.
